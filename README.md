# 🖥️ Atividade Prática - Lógica de Programação e Algoritmos

Este repositório reúne os exercícios desenvolvidos na disciplina de **Linguagem de Programação e Algoritmos (UNINTER)**, por **Caroline da Silva Grau (RU 5282467)**.  
Os programas foram implementados em **Python** e abordam estruturas condicionais, laços de repetição, funções e manipulação de listas/dicionários.

---

## 📌 Questão 1 - Sistema de Descontos em Vendas
- Programa que calcula descontos progressivos conforme o valor da compra:
  - < 2500 → 0%  
  - 2500–5999 → 4%  
  - 6000–9999 → 7%  
  - ≥ 10000 → 11%  
- Utiliza `if`, `elif`, `else` e entradas via `input`.  
- Exibe valor total sem desconto e com desconto.

---

## 📌 Questão 2 - Loja de Açaí e Cupuaçu
- Programa que simula pedidos de açaí e cupuaçu nos tamanhos P, M e G.  
- Valida entradas de sabor e tamanho.  
- Usa `while`, `break`, `continue` e acumulador para somar pedidos.  
- Permite múltiplos pedidos até o cliente encerrar.  
- Exibe cardápio e valor total.

---

## 📌 Questão 3 - Serviços de Copiadora
- Programa que calcula o valor de serviços de digitalização, impressão e fotocópia.  
- Aplica descontos progressivos conforme número de páginas.  
- Valida entradas com `try/except`.  
- Permite adicionar serviços extras (encadernação simples ou capa dura).  
- Exibe valor final detalhado.

---

## 📌 Questão 4 - Sistema de Gerenciamento de Livros
- Programa com menu principal para:
  1. Cadastrar livros  
  2. Consultar livros (todos, por id ou por autor)  
  3. Remover livros  
  4. Encerrar programa  
- Utiliza lista de dicionários para armazenar dados.  
- Implementa funções específicas para cada operação.  
- Exibe mensagens de boas-vindas e valida entradas.
